# Torjäger-Challenge

Belohnungs-App für die Familie: Aufgaben bringen Tore, Karten kosten Minus, Tore führen zu Zielen und Belohnungen, dazu ein Sticker-Album und ein Angel-Spiel. Läuft als Web-App auf dem iPhone-Home-Bildschirm (kein App Store). Der Stand liegt in einer eigenen Firestore-Datenbank (EU) und ist auf allen Geräten live gleich, auch ohne Netz (wird später nachgeschickt).

Dieses Repo enthält nur Programmcode. Zugangsdaten, Familiencode und Stand der Familie stehen **nicht** hier.
